Trả lời câu hỏi lý thuyết

Trình bày ngắn gọn, có ví dụ và lưu ý khi triển khai thực tế.

Câu 1 (10 điểm): position: relative và absolute

relative giữ phần tử trong luồng bố cục bình thường; top/right/bottom/left dịch phần tử so với vị trí ban đầu, nhưng chỗ ban đầu vẫn được giữ. Nó thường dùng làm mốc định vị cho phần tử con. absolute đưa phần tử ra khỏi luồng và định vị theo tổ tiên gần nhất có position khác static; nó không tự dành chỗ trong layout.

.card { position: relative; }
.badge { position: absolute; top: 8px; right: 8px; }

Card làm mốc, nhãn nằm ở góc. Responsive nên dùng Grid/Flexbox, kích thước linh hoạt và media query thay vì tọa độ cố định. Hai thuộc tính không phụ thuộc trực tiếp vào hosting, nhưng layout cố định có thể chồng lấp trên màn hình nhỏ.

Câu 2 (10 điểm): Domain, hosting và DNS

  1. Chọn tên miền và đăng ký qua nhà đăng ký uy tín.
  2. Chọn hosting, tải code lên hoặc kết nối repository Git.
  3. Cấu hình nameserver hoặc bản ghi DNS A/AAAA/CNAME theo hướng dẫn nhà cung cấp.
  4. Bật HTTPS/SSL, chờ DNS cập nhật và kiểm tra trên nhiều thiết bị.

DNS giúp trình duyệt tìm địa chỉ máy chủ tương ứng với tên miền. Các nền tảng deploy tĩnh gồm GitHub Pages và Netlify (có thể dùng Vercel). Rủi ro cấu hình sai gồm website không truy cập được, HTTPS lỗi, chiếm đoạt tên miền hoặc lộ dữ liệu. Bật MFA, phân quyền repository, không đưa API key bí mật vào JavaScript client và không lưu mật khẩu dạng thuần.

Câu 3 (10 điểm): var, let và const

  • var: scope theo function, cho phép khai báo lại, hoist và khởi tạo undefined.
  • let: scope theo block, không khai báo lại cùng scope; hoist nhưng nằm trong temporal dead zone trước khai báo.
  • const: scope block, bắt buộc khởi tạo và không gán lại biến; thuộc tính object vẫn có thể thay đổi.
console.log(score); // ReferenceError
let score = 10;
for (var i=0; i<3; i++) {}
console.log(i); // 3
for (let j=0; j<3; j++) {}
// console.log(j); // ReferenceError

Ưu tiên const, dùng let khi cần gán lại. Debug bằng Chrome DevTools: Console xem lỗi, Sources đặt breakpoint, xem Scope/Call Stack; Network kiểm tra file JS/CSS có tải thành công không.

Câu 4 (10 điểm): Event Delegation

Event Delegation gắn listener lên phần tử cha, tận dụng bubbling để xử lý sự kiện từ phần tử con, kể cả phần tử được thêm sau này.

document.querySelector("#tasks").addEventListener("click", event => {
 const button = event.target.closest("button[data-remove]");
 if (!button || !event.currentTarget.contains(button)) return;
 button.closest("li")?.remove();
});

Kỹ thuật này giảm số listener, dễ bảo trì danh sách động. Kết hợp class CSS cho trạng thái hover/focus, dùng button có nhãn rõ ràng và luôn kiểm tra target hợp lệ.
